Como Salvar os Slides para o Instagram

Instruções de Captura em Alta Resolução (1080x1350)

  1. Abra o post desejado clicando em "Abrir Carrossel".
  2. No navegador (Chrome/Edge), pressione F12 para abrir as Ferramentas de Desenvolvedor.
  3. Pressione Ctrl + Shift + M para ativar a visualização responsiva e defina o tamanho para 1080 x 1350 (DPR 1 ou 2).
  4. Pressione Ctrl + Shift + P, digite "Capture screenshot" ou "Capture node screenshot" selecionando a div .slide.
  5. Ou capture diretamente pelo botão PrintScreen/Ferramenta de Captura do Windows.
